## 本次更新

- 新增 Windows 桌面版：基于 Tauri 2 + WebView2，复用共享 React 阅读器，提供原生窗口、菜单与文件选择器。
- Windows 端沿用 fnOS 完整编辑体验：目录树、工作区、全文搜索、多标签页会话与草稿恢复，平台差异通过能力开关表达。
- 抽象前端传输层，使同一套界面既能走 fnOS 的 HTTP 网关，也能走 Windows 的 Tauri IPC，fnOS 与 macOS 行为保持不变。
- Windows 文件服务实现授权根边界、符号链接与重解析点拒绝、句柄级身份校验与请求取消，防止越权与检查/使用间被替换。
- Windows 安全保存复用跨端 `contracts/safe-save/v1` 契约：原子写入、乐观锁冲突、显式恢复 sidecar，与 fnOS、macOS 共享同一组场景测试。
- 本地图片通过自定义协议按授权边界读取；文件变化由原生监听推送，替代轮询。
- 接入 Windows CI 校验 Rust 格式、编译、测试与静态检查，并在发布流程中构建 NSIS EXE 安装程序。
